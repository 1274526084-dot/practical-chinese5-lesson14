# 《实用汉语5》第14课《第一次打的》

互动课堂网页，包含复习、生词、课文、随文语法、铁路服务情境与课后练习。

- 36个课堂步骤，教材原声与图片均保存在本站。
- 第一次打开从第1步开始；课堂操作保存在当前浏览器中。
- 再次上课可点击右侧“课前重置：回到第1步”。
- 官方视频通过原网站链接观看，需要联网。
- 图片来源保留在课件相应图片下方。

## 发布

GitHub Pages 使用 `main` 分支的根目录。入口文件为 `index.html`，请保留 `assets` 文件夹。

## 本地使用

下载完整文件夹后打开 `index.html`，也可以使用课件；官方视频仍需联网。
